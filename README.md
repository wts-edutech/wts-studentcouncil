# ระบบรับสมัครเลือกตั้งประธานสภานักเรียนและประธานคณะสี ประจำปีการศึกษา 2570
### โรงเรียนวชิรธรรมสาธิต สังกัดสำนักงานเขตพื้นที่การศึกษามัธยมศึกษากรุงเทพมหานคร เขต 2

ระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการการรับสมัครเลือกตั้งผู้นำนักเรียน แบ่งออกเป็นหน้าบ้าน (Frontend) สำหรับนักเรียน/ผู้สมัคร และหลังบ้าน (Admin Backend) สำหรับครูที่ปรึกษาและกลุ่มบริหารกิจการนักเรียน พร้อมระบบพิมพ์แบบฟอร์มกระดาษ A4 มาตรฐานทางราชการ

---

## 🌟 ฟังก์ชันหลักของระบบ

### 1. หน้าบ้าน (Frontend / Public Portal) - `index.html`
- **แบนเนอร์ประชาสัมพันธ์ & ข้อมูลกำหนดการเลือกตั้ง 2570** (Timeline ปฏิทินรับสมัคร, ตรวจคุณสมบัติ, หาเสียง, วันเลือกตั้ง)
- **เกณฑ์และคุณสมบัติการรับสมัครทั้ง 2 ตำแหน่ง** (สภานักเรียน และ 5 คณะสี)
- **ระบบค้นหา & ตรวจสอบสถานะใบสมัคร** ค้นหาด้วยเลขประจำตัวนักเรียน 5 หลัก หรือชื่อ หรือชื่อพรรค พร้อมปุ่มสั่งพิมพ์ใบสมัคร A4
- **ช่องทางสมัครออนไลน์ 2 รูปแบบ**:
  1. สมัครเลือกตั้งประธานสภานักเรียน 2570
  2. สมัครเลือกตั้งประธานคณะสี 2570 (5 คณะสี)

### 2. ใบสมัครเลือกตั้งประธานสภานักเรียน - `apply-council.html`
- สมัครในรูปแบบพรรคการเมือง (10 ตำแหน่งตามโครงสร้างที่กำหนด):
  1. ผู้ลงสมัครประธานสภานักเรียน (ม.4)
  2. ผู้แทนพรรคเพื่อดำรงตำแหน่งรองประธานพรรค
  3. ผู้แทนพรรคเพื่อดำรงตำแหน่งฝ่ายวิชาการ (คนที่ 1)
  4. ผู้แทนพรรคเพื่อดำรงตำแหน่งฝ่ายวิชาการ (คนที่ 2)
  5. ผู้แทนพรรคเพื่อดำรงตำแหน่งฝ่ายสันทนาการ (คนที่ 1)
  6. ผู้แทนพรรคเพื่อดำรงตำแหน่งฝ่ายสันทนาการ (คนที่ 2)
  7. ผู้แทนพรรคเพื่อดำรงตำแหน่งฝ่ายทั่วไป
  8. ผู้แทนพรรคเพื่อดำรงตำแหน่งฝ่ายประชาสัมพันธ์ (คนที่ 1)
  9. ผู้แทนพรรคเพื่อดำรงตำแหน่งฝ่ายประชาสัมพันธ์ (คนที่ 2)
  10. ผู้แทนพรรคเพื่อดำรงตำแหน่งเลขานุการ
- **ข้อมูลที่กรอกในทุกตำแหน่ง**:
  - ชื่อ - นามสกุล
  - ชั้น ม.4 และห้อง (ม.4/1 - ม.4/8)
  - เลขประจำตัวนักเรียน (5 หลัก)
  - คะแนนพฤติกรรม (คงเหลือ ณ วันสมัคร ไม่ต่ำกว่า 80 คะแนน)
  - เกรดเฉลี่ยสะสม (ม.4 ภาคเรียนที่ 1)
  - เบอร์โทรศัพท์
  - แนบไฟล์รูปถ่ายนักเรียน (ขนาด 1.5 - 2 นิ้ว พร้อมพรีวิวทันที)
  - ช่องกดยอมรับ **ข้อตกลงของสภานักเรียน โรงเรียนวชิรธรรมสาธิต ประจำปีการศึกษา 2568**
- มีปุ่ม **"เติมข้อมูลตัวอย่าง (Demo)"** เพื่อความสะดวกในการทดสอบระบบ

### 3. ใบสมัครเลือกตั้งประธานคณะสี - `apply-color.html`
- **ครอบคลุม 5 คณะสี**:
  1. คณะสีอัญชัน (น้ำเงิน/ม่วง)
  2. คณะสีนนทรี (เหลือง)
  3. คณะปาริชาต (แดง)
  4. คณะสีเอื้องช่อแสด (แสด/ส้ม)
  5. คณะสีอินทนิล (เขียว)
- ข้อมูลผู้สมัครประธานคณะสี และสมาชิกแต่ละคนในพรรค/คณะทำงาน
- กรอกคุณสมบัติครบถ้วน (ม.4 ห้อง, เลขประจำตัว, คะแนนพฤติกรรม >= 80, GPAX ม.4 เทอม 1 >= 2.50, เบอร์โทร, แนบรูปถ่าย)
- ช่องกดยอมรับ **ข้อตกลงของสภานักเรียน โรงเรียนวชิรธรรมสาธิต ประจำปีการศึกษา 2567**
- เพิ่ม/ลบสมาชิกในทีมได้ตามต้องการ พร้อมปุ่ม Demo เติมข้อมูลทดสอบ

### 4. แบบฟอร์มใบสมัครกระดาษ A4 - `print-application.html`
- ออกแบบตามระเบียบงานสารบรรณโรงเรียน ขนาด A4 (210 x 297 mm) พอดี 1 หน้ากระดาษ
- มีตราสัญลักษณ์โรงเรียนวชิรธรรมสาธิต
- แสดงรูปถ่ายนักเรียนที่แนบมา หรือกรอบติดรูปขนาด 1.5 นิ้ว
- ตารางสรุปข้อมูล 10 ตำแหน่งสภานักเรียน หรือคณะทำงานคณะสี
- ช่องลายมือชื่อ 3 ส่วน:
  1. ผู้สมัครประธาน
  2. ครูที่ปรึกษาพรรค/คณะสี
  3. หัวหน้ากลุ่มบริหารกิจการนักเรียน (สำหรับเจ้าหน้าที่ตรวจรับ)
- รองรับทั้งพิมพ์ข้อมูลที่กรอก หรือสลับเป็นแบบฟอร์มเปล่าเพื่อนำไปเขียนด้วยมือ

### 5. ศูนย์ดาวน์โหลดเอกสารทางการ - `documents.html`
- **หนังสือยินยอมจากผู้ปกครอง (Parental Consent Form)**: แสดงตัวอย่างและพิมพ์แบบฟอร์ม A4 ให้ผู้ปกครองลงนามได้ทันที
- **แบบฟอร์มขอใบรับรองคะแนนพฤติกรรม**: คำร้องขอตรวจและรับรองคะแนนความประพฤติจากกลุ่มบริหารกิจการนักเรียน
- **ประกาศและเกณฑ์การรับสมัครฉบับเต็ม**

### 6. ระบบบริหารจัดการหลังบ้าน (Admin Dashboard) - `admin.html`
- บัญชีเข้าใช้งาน: `admin` / รหัสผ่าน: `1234`
- สรุปสถิติผู้สมัครแบบเรียลไทม์ (สภานักเรียน และแยก 5 คณะสี)
- ตรวจสอบคุณสมบัติ / อนุมัติ / ตีกลับให้แก้ไข
- กำหนด **"หมายเลขประจำตัวผู้สมัคร / หมายเลขพรรค"** (เช่น เบอร์ 1, เบอร์ 2)
- บันทึกข้อเสนอแนะของกรรมการ
- พิมพ์ใบสมัคร A4 โดยตรงจากหลังบ้าน
- ส่งออกข้อมูลเป็น **Excel (CSV)** รองรับภาษาไทย UTF-8

## 🚀 วิธีการเปิดใช้งาน

### วิธีที่ 1: ดับเบิลคลิกไฟล์ (ง่ายที่สุด)
- ดับเบิลคลิกที่ไฟล์ `start.bat` ในโฟลเดอร์นี้ ระบบจะเปิดเว็บเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:3000`
- หรือดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานได้ทันทีโดยตรงใน Google Chrome / Edge

### วิธีที่ 2: รันผ่าน Node.js
```bash
node server.js
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`
